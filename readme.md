# 角色设定
你是一位精通 Tailwind CSS、原生 JS 以及交互动画的高级前端工程师。非常擅长设计“氛围感”、“治愈系”和“Vibe Coding”风格的现代个人主页。

# 任务目标
根据我的要求风格，在不影响功能的正常运行下对整个网站进行前端重构，包括二级功能页面也需要重构，只要不影响正常使用。并且适当运用你刚安装的Skill。

# 视觉风格（薰衣草淡紫色主题）
1. **配色方案**：
   - 主色系：薰衣草淡紫色（Lavender），参考色值 `#B39DDB`, `#D1C4E9`, `#EDE7F6`。
   - 辅助色：奶油白、半透明白、柔和的薄荷绿 `#E0F2F1` 作为点缀。
   - 背景：采用柔和、晕染的**淡紫到粉白到淡蓝**的渐变色（Soft Gradient），营造梦幻、舒适的氛围。
2. **UI 组件风格**：
   - 大量使用**大圆角（Rounded-3xl）**、**柔和阴影（Soft Shadow）** 和 **磨砂玻璃质感（Glassmorphism）**。
   - 字体采用简洁无衬线字体（如 Inter、PingFang SC），标题字体超大且优雅，正文字体清晰细致。
   - 间距宽松，注重留白，所有的模块像悬浮的画板。

# 页面结构与模块（无需时间轴，全新功能分区）
页面采用纵向滚动布局，从上到下依次为：

## 模块一：顶部导航栏（固定头部）
- 样式：磨砂玻璃圆角药丸形状（宽屏居中，移动端自适应）。
- 内容：左侧 Logo（文字"南渝万能墙"），中间各模块导航链接（稿件查询、有求必应、公益课程、共创计划、招贤纳士、关于我们），右侧一个“立即进入”按钮。导航悬停有背景色变化，菜单项点击自动跳转至对应板块。logo照片使用public的logomini.webp。

## 模块二：品牌形象主视觉区（Hero Section）
- 布局：左右分栏。
- 左侧：大字标题 "Hi, 这里是南渝万能墙"，副标题 "Nanyu Server - 2024 - 使用淡紫色高亮，下方是介绍文字“南渝万能墙隶属于重庆校墙联，以服务好南渝师生为宗旨。于2024年创立”，以及“进入万能墙”和“北关鱼的驿站”两个胶囊按钮。
- 右侧：放置一个带有晕圈的LOGO照片，风格柔和小清新。logo照片使用public的logomini.webp。

## 模块三：随机抽取同学投稿区（核心交互模块）
- **标题**：01 / PART，主标题“试试抽取一份同学投稿”。
- **交互设计**：左侧是一个**叠放卡牌**效果（看起来像一沓卡片），右侧是一个单独显示的**放大卡片**。
- 下方有一个黑色胶囊按钮，写着“随机抽一张”。
- **逻辑实现（重点）**：通过已经连接好的稿件数据库实现数据同步（包含：投稿内容、稿件类型、投稿时间）。用户点击“随机抽一张”按钮时，左侧的卡片堆叠会有一个发牌动画，右侧的大卡片从下往上翻转展开，展示抽到的具体投稿内容（投稿内容、稿件类型、投稿时间）。
- **动效要求**：有平滑的 CSS 过渡动画（Transition），而非生硬的显示。

## 模块四：平台核心功能区（替换原本作品展示，实现跳转）
- **标题**：02 / FUNCTION，主标题“为你的校园保驾护航”。
- **内容**：以 **2x2 网格布局** 展示四个功能卡片，每个卡片都必须能点击并**跳转到对应的网页**。
- **功能卡片 1：稿件查询**。图标用放大镜，描述为“查阅南渝万能墙的稿件”。
- **功能卡片 2：有求必应**。图标用握手/问答，描述为“提出需求，互帮互助”。
- **功能卡片 3：公益课程**。图标用书本/爱心，描述为“免费公开课程资源”。
- **功能卡片 4：共创计划**。图标用星星/大脑，描述为“在北关鱼的驿站发稿”。
- **交互要求**：鼠标悬停任意卡片时，卡片轻微上浮（translateY），并伴有阴影加深效果。点击卡片时，使用 `window.open` 或 `a href` 跳转到对应的 URL（跳转到对应界面）。

## 模块五：页脚区
- 居中显示版权信息，以及一个“回到顶部”的按钮。
- 背景融入渐变，保持薰衣草色系的统一。
